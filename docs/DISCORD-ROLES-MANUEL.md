# Rôles Discord REDLAKES — guide manuel

## Règles importantes

1. **Pas de système de niveaux** — on promeut selon la qualité du RP global, pas automatiquement.
2. **Elite / Prestige = titres**, pas des grades. Un joueur reste Sergent, Caporal ou Soldat et reçoit en plus `🏅 Elite` ou `⭐ Prestige`.
3. **Illégal libre** — pas de rôles crime fixes. Les joueurs fondent gang, mafia, MC, cartel… Le staff crée le rôle Discord quand c'est validé en RP.
4. **Emojis** — recommandés sur les noms de rôles pour la lisibilité.

Crée d'abord les **séparateurs** (rôles vides, affichés à part, 0 permission), puis les grades en dessous.

## 🌃 ILLÉGAL — ORGS LIBRES

**Pas de rôles fixes ici.** Quand un groupe est validé en RP, crée un rôle du type :

- `💀 [Nom du Gang]` — ex. Les Vipers
- `🍝 [Nom Mafia]` — ex. Famille Moretti
- `🏍️ [Nom MC]` — ex. Iron Riders MC
- `💊 [Nom Cartel]` — ex. Cartel del Norte

Types possibles : **Gang** · **Mafia / Famille** · **Motorcycle Club (MC)** · **Cartel** · **Org indépendante**
